# 운동 기록

휴대폰에서 한 손으로 쓰기 좋게 만든 웨이트·유산소 운동 기록 웹앱입니다. 월간 달력에서 운동한 날과 부위를 한눈에 보고, 날짜를 눌러 그날의 세트를 기록합니다. 홈 화면에 설치하면 앱처럼 열리고 인터넷 없이도 동작합니다.

**접속 주소: https://adkfjadklfjal.github.io/workout-log/**

HTML, CSS, JavaScript만으로 만들었고 외부 라이브러리나 서버는 쓰지 않습니다. 기록은 브라우저의 localStorage에 저장되므로 기기마다 따로 남고, 기기끼리 동기화되지 않습니다.

## 기능

### 달력
- 월간 달력, 이전 달/다음 달 이동, 오늘 날짜 강조
- 운동한 날에는 그날 한 부위를 색깔 라벨로 표시 (많으면 `+2`처럼 줄여서 표시)
- 달력 위 '오늘 뭐 할까' 요약: 부위별로 마지막으로 한 지 며칠 지났는지 오래된 순으로 표시
- 날짜를 길게 눌러 끌어다 다른 날짜에 놓으면 그날 기록 복사 (가장자리로 끌면 다른 달로 이동, 폰 터치와 PC 마우스 모두 지원)
- 끌다가 아래쪽 휴지통에 놓으면 그날 기록 전체 삭제
- 복사·삭제 직후 '되돌리기' 안내로 실수 취소

### 기록 화면
- 이전 날/다음 날 화살표, 뒤로 버튼과 폰의 뒤로가기로 달력 복귀
- 운동 추가·수정·삭제, 카드를 왼쪽으로 밀어 삭제 (되돌리기 가능)
- 부위(가슴, 등, 하체, 어깨, 팔, 복근, 유산소, 기타)를 고른 뒤 기본 종목 버튼에서 선택
- 직접 입력한 종목은 목록에 추가되고, 길게 눌러 지울 수 있음
- 최근에 한 종목이 앞에 오도록 정렬하고 검색으로 걸러 보기
- 같은 종목의 지난 기록(날짜, 며칠 전, 세트별 무게와 횟수, 추정 1RM) 표시
- 운동 카드에 추정 1RM(Epley 공식)과 직전 기록이 며칠 전인지 표시, 처음 하는 종목은 '첫 기록'
- 이전 최고 추정 1RM을 넘으면 '신기록' 배지
- 유산소는 시간(분)과 거리(km)로 기록하고 평균 페이스 계산, 총 볼륨과 따로 유산소 총 시간 표시

### 휴식 타이머
- 세트 완료를 체크하면 휴식 타이머가 자동으로 시작
- 화면 아래 막대에 남은 시간 표시, +30초 / -30초 / 건너뛰기
- 60·90·120·180초 중에서 고르고, 고른 값은 저장
- 끝나면 소리와 진동으로 알림 (지원하는 기기만)
- 끝나는 시각 기준으로 계산하므로 화면을 껐다 켜도 남은 시간이 정확함

### 종목별 추이
- 종목 이름을 누르면 날짜별 추정 1RM 꺾은선 그래프(SVG로 직접 그림)
- 최고 추정 1RM, 최고 무게, 총 수행 일수 표시
- 유산소는 날짜별 시간과 거리 변화 표시

### 설치형 앱 (PWA)
- 아이폰·안드로이드 홈 화면에 설치 가능, 주소창 없이 앱처럼 실행
- 서비스 워커가 모든 파일을 캐시해서 인터넷 없이도 열림

## 설치 방법

### 아이폰 (Safari)
1. Safari로 https://adkfjadklfjal.github.io/workout-log/ 를 엽니다. (다른 브라우저에서는 홈 화면 추가가 안 될 수 있습니다.)
2. 아래쪽 공유 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 누르고 **추가**를 누릅니다.

### 안드로이드 (Chrome)
1. Chrome으로 https://adkfjadklfjal.github.io/workout-log/ 를 엽니다.
2. 오른쪽 위 ⋮ 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다. 화면 아래에 설치 안내가 바로 뜨기도 합니다.
3. **설치**를 누릅니다.

### PC에서 직접 실행하기
저장소를 내려받은 뒤 폴더에서 정적 서버를 띄우고 `http://localhost:8000`을 엽니다. 서비스 워커는 `file://`로 열면 동작하지 않으므로 서버로 열어야 합니다.

```sh
python -m http.server 8000
```

## 사용한 프롬프트

이 앱은 Claude Code에 아래 프롬프트를 순서대로 입력해서 만들었습니다.

1. ```text
   git init 해줘.
   ```

2. ```text
   운동 기록 앱의 화면을 HTML/CSS/JS로 만들어줘. 아직 기능은 없어도 돼.
   - 위쪽에 날짜 선택, 가운데에 오늘 운동 목록(종목, 세트, 횟수, 무게)
   - 아래쪽에 운동 추가 버튼
   - 휴대폰 화면 기준으로 한 손으로 누르기 좋게
   - 디자인: 밝은 배경, 포인트 색은 초록, 깔끔한 한글 글꼴
   - 파일: index.html, style.css, app.js (경로는 모두 상대 경로)
   다 만들면 브라우저에서 열어줘.
   ```

3. ```text
   지금까지 변경사항을 커밋해줘.
   ```

4. ```text
   운동 추가 버튼을 누르면 종목, 세트, 횟수, 무게를 입력해서 선택한 날짜에 기록을 추가할 수 있게 해줘. 수정과 삭제도 되게 해줘. 데이터는 localStorage에 저장해서 새로고침해도 남게 하고, 샘플 데이터는 지워줘. 한글 입력 중에 Enter가 두 번 처리되지 않게 해줘. 끝나면 커밋해줘.
   ```

5. ```text
   종목을 입력할 때 전에 썼던 종목 이름이 추천으로 뜨게 하고, 같은 종목의 지난 기록(무게, 횟수)을 입력창 아래에 보여줘. 끝나면 커밋해줘.
   ```

6. ```text
   다음 기능을 추가해줘.
   - 1RM 추정: 각 운동 카드에 그날 세트 중 가장 높은 추정 1RM을 표시해줘. 공식은 Epley(무게 × (1 + 횟수/30))를 쓰고, 1회는 그 무게 그대로, 무게가 0인 세트는 제외해줘. 소수점 첫째 자리까지 보여줘.
   - 지난 기록: 운동 추가 창에서 종목을 입력하면 전에 썼던 종목 이름이 추천으로 뜨고, 같은 종목의 가장 최근 기록(날짜, 며칠 전인지, 세트별 무게와 횟수, 추정 1RM)을 입력창 아래에 보여줘. 이미 만든 부분이 있으면 그대로 살려서 보완해줘.
   - 운동 카드에도 이 종목을 직전에 한 게 며칠 전인지 표시해줘. 처음 하는 종목이면 '첫 기록'이라고 보여줘.
   끝나면 커밋해줘.
   ```

7. ```text
   앱 구조를 바꿔줘. 첫 화면을 월간 달력으로 하고, 날짜를 누르면 그날의 기록 화면으로 들어가게 해줘.
   - 달력 화면: 한 달 달력, 이전 달/다음 달 이동, 오늘 날짜 강조. 운동한 날은 칸 안에 그날 한 부위를 색깔 있는 작은 라벨로 보여줘(부위마다 다른 색). 폰 화면에서 글자가 잘리지 않게, 많으면 '+2'처럼 줄여줘.
   - 달력 위에 '오늘 뭐 할까' 요약: 부위별로 마지막으로 한 게 며칠 전인지 오래된 순서로 보여줘.
   - 날짜를 누르면 지금의 기록 화면(운동 카드, 추정 1RM, 직전 기록, 운동 추가/수정/삭제)이 그 날짜로 열리게 해줘. 위쪽에 달력으로 돌아가는 뒤로 버튼을 두고, 폰의 뒤로가기 버튼으로도 달력으로 돌아가게 해줘.
   - 기록 화면의 주간 날짜 줄은 없애고, 대신 이전 날/다음 날로 넘기는 화살표만 남겨줘.
   - 기존 기록 데이터(localStorage)는 그대로 유지해줘.
   끝나면 커밋해줘.
   ```

8. ```text
   달력에 '기록 복사' 기능을 추가해줘.
   - 달력 화면에 '기록 복사' 토글 버튼을 두고, 켜면 복사 모드가 되게 해줘.
   - 복사 모드에서 먼저 기록이 있는 날짜를 누르면 그날이 복사할 원본으로 선택되고, 그다음 누르는 날짜에 그날의 운동(종목, 부위, 세트별 횟수와 무게)이 똑같이 복사되게 해줘. 여러 날짜에 연달아 붙여넣을 수 있게 하고, 토글을 끄면 복사 모드가 끝나게 해줘.
   - 화면 위쪽에 지금 단계가 보이게 안내 문구를 넣어줘(예: '복사할 날짜를 고르세요' → '10월 9일 기록을 붙여넣을 날짜를 고르세요').
   - 붙여넣을 날짜에 이미 기록이 있으면 덮어쓰지 말고 뒤에 추가해줘. 복사된 기록은 새 id를 받아서 원본과 따로 수정·삭제되게 해줘.
   - 붙여넣은 직후에는 '되돌리기' 버튼이 있는 안내를 잠깐 띄워서 실수로 넣은 걸 취소할 수 있게 해줘.
   - 복사 모드가 꺼져 있을 때는 날짜를 누르면 평소처럼 그날 기록 화면으로 들어가게 해줘.
   끝나면 커밋해줘.
   ```

9. ```text
   달력에서 기록을 끌어다 놓아 복사하는 기능을 만들어줘. 토글 방식의 '기록 복사' 모드가 이미 있으면 없애고 이걸로 바꿔줘.
   - 달력에서 기록이 있는 날짜를 길게 누르면(약 0.4초) 그날 기록이 손가락을 따라오는 작은 미리보기로 떠오르고, 그대로 끌어서 다른 날짜 칸에 놓으면 그날의 운동(종목, 부위, 세트별 횟수와 무게)이 똑같이 복사되게 해줘.
   - 폰 터치와 PC 마우스 모두 되게 pointer 이벤트로 만들어줘. 끄는 동안에는 화면 스크롤과 글자 선택, 길게 누르기 메뉴가 뜨지 않게 하고, 손가락 아래의 날짜 칸을 강조해줘. 길게 눌렀을 때 진동(지원되는 기기만)도 넣어줘.
   - 달력 가장자리로 끌고 가면 이전 달/다음 달로 넘어가서 다른 달에도 놓을 수 있게 해줘.
   - 짧게 누르면 평소처럼 그날 기록 화면으로 들어가게 하고, 달력 밖이나 원래 날짜에 놓으면 아무 일도 일어나지 않게 해줘.
   - 놓은 날짜에 이미 기록이 있으면 덮어쓰지 말고 뒤에 추가해줘. 복사된 기록은 새 id를 받아서 원본과 따로 수정·삭제되게 해줘.
   - 놓은 직후에는 '되돌리기' 버튼이 있는 안내를 잠깐 띄워줘.
   - 달력 아래에 '길게 눌러 끌면 다른 날짜로 복사돼요'라는 작은 안내 문구를 넣어줘.
   끝나면 커밋해줘.
   ```

10. ```text
    달력에서 기록을 바로 삭제할 수 있게 해줘.
    - 날짜를 길게 눌러 끌기 시작하면 화면 아래쪽에 휴지통 영역이 나타나고, 거기에 놓으면 그날 기록 전체가 삭제되게 해줘. 휴지통 위에 올라가면 빨갛게 강조해줘.
    - 삭제 직후에는 '되돌리기' 버튼이 있는 안내를 5초 정도 띄워서 실수로 지운 걸 복구할 수 있게 해줘. 확인 창은 따로 띄우지 마.
    - 그날 운동 중 일부만 지우고 싶을 때를 위해, 기록 화면의 운동 카드를 왼쪽으로 밀면 삭제 버튼이 나오게 해줘. 이것도 삭제 후 되돌리기가 되게 해줘.
    - 달력 아래 안내 문구를 '길게 눌러 끌면 다른 날짜로 복사, 휴지통에 놓으면 삭제'로 바꿔줘.
    끝나면 커밋해줘.
    ```

11. ```text
    운동 추가 창의 종목 선택을 부위 기준으로 바꿔줘.
    - 맨 위에서 부위(가슴, 등, 하체, 어깨, 팔, 복근, 유산소, 기타)를 먼저 고르면, 그 부위의 종목 목록이 버튼으로 나오고 누르면 종목이 선택되게 해줘.
    - 부위별 기본 종목을 미리 넣어줘.
      - 가슴: 벤치프레스, 인클라인 벤치프레스, 덤벨프레스, 인클라인 덤벨프레스, 체스트프레스 머신, 펙덱 플라이, 케이블 크로스오버, 딥스, 푸시업
      - 등: 데드리프트, 풀업, 랫풀다운, 바벨로우, 덤벨로우, 시티드 케이블로우, 티바로우, 암풀다운
      - 하체: 스쿼트, 레그프레스, 런지, 레그익스텐션, 레그컬, 루마니안 데드리프트, 힙쓰러스트, 카프레이즈
      - 어깨: 오버헤드프레스, 덤벨 숄더프레스, 사이드 레터럴 레이즈, 프론트 레이즈, 리어 델트 플라이, 페이스풀, 슈러그
      - 팔: 바벨컬, 덤벨컬, 해머컬, 케이블 푸시다운, 라잉 트라이셉스 익스텐션, 오버헤드 익스텐션
